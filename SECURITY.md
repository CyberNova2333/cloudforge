# Security policy

Please report vulnerabilities privately to the maintainer, [CyberNova](https://cnb.cool/CyberNova2333), on CNB rather
than opening a public issue in [the repository](https://cnb.cool/CyberNova2333/cloudforge). Include steps to reproduce
and the impact you observed. We'll acknowledge the report and keep you updated on the fix.

This is an independent fork: please don't report issues in this fork to the upstream GitOrange project.
