# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 与普通的 Cloudflare Workers 有何不同？

**A**: Cloudforge 在纯 Worker 之上提供了一层无状态的工作流编排与分布式持久化机制，适合多步骤、带状态转移与复杂重试机制的任务。

### Q: 支持本地无网离线测试吗？

**A**: 支持。通过内置的内存 SQLite 与 Mock 驱动，在本地执行 `pnpm test` 无需连接任何云端服务即可全绿运行。

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
