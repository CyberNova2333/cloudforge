# Glossary

| Term                                            | Meaning in CloudForge                                                                                          | More                                                                              |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **Cloudflare Artifacts**                        | Managed Git object/ref store bound as `ARTIFACTS` (1 GB/repo cap, Git protocol v1)                             | [Git, Artifacts & R2 LFS](/en/docs/modules/git-and-storage)                       |
| **`ActionsRun` / `JobRunner` / `ActionsQueue`** | Workflow orchestrator, Container DO (`standard-1`..`4`), and instance/repo concurrency queue                   | [Actions Containers & Webhooks](/en/docs/modules/actions-containers-and-webhooks) |
| **`MergeResolutionWorkflow` / `AgentReviewer`** | Orchestration Workflow and per-attempt isolated DO workspace for `engine: pi` reviews and `learn`              | [Reviews, Stacking & Auto-Merge](/en/docs/modules/reviews-stacking-and-merge)     |
| **`LiveHub`**                                   | Hibernating DO maintaining browser `/api/live` WebSockets and emitting data-free invalidation pings            | [Architecture](/en/docs/architecture)                                             |
| **`land_target` vs `base_ref`**                 | Final landing target branch vs temporary stacked parent branch updated in D1 only                              | [Reviews, Stacking & Auto-Merge](/en/docs/modules/reviews-stacking-and-merge)     |
| **`pr_edges` / `reviewVerdict`**                | DAG stacking edge table and single shared review-gate predicate read across UI, API, auto-merge, and MCP       | [Reviews, Stacking & Auto-Merge](/en/docs/modules/reviews-stacking-and-merge)     |
| **`AGENT.md` & `agent_lessons`**                | Per-agent config repo manifest and queued learning tasks created from dismissed change requests / teach notes  | [Reviews, Stacking & Auto-Merge](/en/docs/modules/reviews-stacking-and-merge)     |
| **`push_events`**                               | Durable D1 outbox persisted before acknowledging pushes to survive `waitUntil` truncation                      | [Walkthrough](/en/docs/walkthrough)                                               |
| **`access_runtime_state`**                      | Singleton D1 protocol gate (`compat-v1` / `runtime-bridge-v1`) causing fail-closed `503` on mismatched Workers | [Auth, OIDC & Access Runtime](/en/docs/modules/auth-oidc-and-access)              |
| **`mcp_moderators`**                            | Explicit opt-in flag unlocking 3 approval tools on a connected `/mcp` OAuth app                                | [Auth, OIDC & Access Runtime](/en/docs/modules/auth-oidc-and-access)              |
| **Deploy Token (`cfd_`)**                       | Repo-scoped Git/LFS-only machine token bound to immutable `repository_id`                                      | [Git, Artifacts & R2 LFS](/en/docs/modules/git-and-storage)                       |
| **`cloudforge/relevance@v1`**                   | Built-in CI workflow action selecting affected test modules via `SUMMARY_MODEL`                                | [Actions Containers & Webhooks](/en/docs/modules/actions-containers-and-webhooks) |
